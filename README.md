# PadForge Plugins

Default plugin pack for [PadForge](https://github.com/yoro1836/padforge).

## Plugins

| File | Description |
|------|-------------|
| `deadzone.lua` | Circular deadzone filter (‰-based per stick) |
| `square.lua` | Circular→square stick mapping |
| `calibrate.lua` | Stick center offset correction |

## Install

Copy `.lua` files into the PadForge plugins directory.
Use the WebUI to enable/disable and configure each plugin.
